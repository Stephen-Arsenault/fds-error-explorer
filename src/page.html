How an FDS disk loads

The Famicom Disk System was a 1986 add-on that let Nintendo's console load games from a small floppy disk instead of a cartridge. When you switch it on, a program burned into the console-side hardware — the BIOS — spins up the drive, reads the game off the disk into memory, and starts it.

The data on a disk is written as a series of blocks, read strictly in order: an identification block naming the game, a count of how many files follow, then for each file a small header followed by the file's data.

The BIOS checks something at nearly every step. If a check fails it stops the drive and puts a two-digit number on screen — sometimes with a word above it, often without. That number is what this page decodes.

Behaviour is traced from one 8 KB BIOS image by static analysis; nothing was executed or emulated, and addresses are the ROM's own, mapped at $E000. Where a field's meaning is inferred from its position rather than confirmed by the ROM's own text, the entry says so.

Some details cannot be derived from the ROM at all — what the disk's header fields are called, what the media physically looks like, and how the drive senses it. Those come from the NESdev Wiki and community hardware documentation.

Exactly what came from those sources
  • The disk-info header's field names and offsets ($0F licensee code through $18). Which error code guards which byte is from the ROM; the names are the format spec's. Only $07 (side) and $08 (disk number) are independently confirmed by the BIOS's own message strings.
  • The two values of the disk type field at $17 — $01 for blue-disk (FMC) releases, $00 otherwise.
  • That the field at $18 has no known purpose and reads $00 on every commercial game examined. That is essentially all of ERR.10.
  • The write-protect tab: where it sits on the card, that a broken tab means protected, the tape repair, and the sensing lever that misreports when dirty.
  • That the protect bit in $4032 also reads 1 for an ejected disk.
  • Blue Disk Cards: the sliding shutter, the missing top-edge protrusion, and the Disk Fax high-score service they were made for.
